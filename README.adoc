= Agentic Email Integration

Own-your-inbox Gmail integration: Himalaya poller + Cursor agents for drafts and CI.

link:https://github.com/dev-centr/agentic-email-integration/issues[Report Bug] ·
link:https://github.com/dev-centr/agentic-email-integration/issues[Request Feature]

== About The Project

Local **integration** into your owned Gmail: poll with https://github.com/pimalaya/himalaya[Himalaya], classify developer/CI mail, trigger a Cursor agent to draft replies or investigate failures.

This is not a disposable AgentMail-style inbox. You keep the mailbox, OAuth, and vendor connections.

=== Status

Early scaffold (`0.1.0`). Draft-only by design.

== Installation

[source,bash]
----
pnpm install
pnpm build
pnpm link --global   # optional: exposes `aei`
----

Node.js **22.13+** required (`@cursor/sdk`).

== Usage

[source,bash]
----
cp config.example.json5 config.local.json5
# edit account, rules, repoRoots
export CURSOR_API_KEY=cursor_...   # or set in the environment on Windows

pnpm aei doctor
pnpm aei check --dry-run
pnpm aei watch
----
