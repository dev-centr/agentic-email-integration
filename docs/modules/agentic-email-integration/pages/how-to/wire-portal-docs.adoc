Component name:: `agentic-email-integration`
Start path:: `docs`

== Production playbook

In `dev-centr/docs` `antora-playbook.yml`, add:

[source,yaml]
----
- url: https://github.com/dev-centr/agentic-email-integration.git
  branches: HEAD
  start_path: docs
----

== Local playbook

In `antora-playbook-local.yml` (from the example):

[source,yaml]
----
- url: ../agentic-email-integration
  branches: HEAD
  start_path: docs
  worktrees: true
----
